# go-tari-tools

Extracted Tari tooling and binaries (faucet, payout utilities, and other tools previously co-located with library code in individual go-tari-* repos). Uses [go-tari-lib](https://github.com/Snipa22/go-tari-lib) and [go-tari-grpc-lib](https://github.com/Snipa22/go-tari-grpc-lib) as dependencies.

This repo aggregates multiple independent binaries — uses release-please's monorepo mode (per-path versioning), not `simple`.
